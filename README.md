## Contents
- `German_Credit_CSET485_Assignment.ipynb` – main notebook for the complete analysis.
- `cset485_analysis.py` – reusable preprocessing, model, stress-test and output code.
- `data/german.data` – raw UCI data file committed to this repository.
- `data/README.md` – dataset provenance and class mapping.
- `outputs/` – generated CSV tables, summary JSON and fairness chart after running the notebook.
- `requirements.txt` – Python dependencies.

## Run the project
1. Clone or download this repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Open `German_Credit_CSET485_Assignment.ipynb` in Jupyter.
4. Run all cells from top to bottom. If `data/german.data` is absent, the script downloads the committed raw copy.
5. Check the generated tables and figures in `outputs/`.

The original UCI target is coded `1 = Good` and `2 = Bad`. Following the handout's binary approval encoding, this project maps Good to approval=1 and Bad to approval=0. This is a coursework proxy, not a record of actual bank lending decisions.

The notebook fits OLS and logistic regression on the same 70/30 split; compares the two threshold rules; and completes the four required stress tests: subgroup analysis, omitted-variable analysis, confident-error subset construction, and a fairness threshold sweep. Every reported number is generated by the notebook and the accompanying script.
