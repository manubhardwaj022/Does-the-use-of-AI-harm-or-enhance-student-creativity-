## Run the code
```bash
pip install -r requirements.txt
python creativity_evidence_analysis.py
```
Or open the notebook in Jupyter and run all cells from the repository root.

## Scope and limitations
This is a focused narrative review of six published studies involving university or undergraduate learners. The CSV is a manually coded study-level evidence matrix, **not raw student-level data**. The code validates the matrix and generates descriptive study counts only; it does not train a predictive model, calculate a pooled effect size, or claim that a new student experiment was conducted. Numerical findings are cited to the original publications in the assignment report.

The original CSET485 handout contains a separate dataset-specific modelling brief. This project uses the requested student-creativity topic and adapts the handout's academic progression and section structure. Please confirm with the instructor that this topic substitution is accepted before submitting.
