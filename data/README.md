# Dataset provenance

`german.data` is the original symbolic 21-column UCI Statlog (German Credit Data) file (20 predictors and one class label).

- Dataset page: https://archive.ics.uci.edu/dataset/144/statlog+german+credit+data
- Citation: Hofmann, H. (1994). *Statlog (German Credit Data)* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5NC77
- UCI dataset: 1,000 records, 20 input features, no missing values.
- Original class: `1 = Good`, `2 = Bad`.
- Coursework mapping: `Good -> approval=1`, `Bad -> approval=0`.

The data are historical and should not be treated as a current or representative lending sample.
